# K-BIZ — Global Rules

These rules govern all work on this project and take precedence over general
coding conventions or default assumptions.

1. **Do not redesign the project.** The visual design and structure are already
   defined by the project owner's Figma designs.

2. **Do not replace the layout with generic cards.** The editorial, exhibition-like
   layout is intentional and must be preserved.

3. **Do not simplify custom graphics.** Visual richness and density are part of the
   intended design language, not something to streamline.

4. **Do not recreate the charm assets.** The ~150–200 group charms already exist as
   SVG or image files and must be used as-is.

5. **Do not invent data.** All group data (members, nationality, formation method,
   language, activity status, company size, etc.) must come from the supplied data
   source — never fabricated or guessed.

6. **The supplied data and Figma designs are the source of truth** for all content,
   layout, and visual decisions.

7. **Ask before making an important visual or structural assumption.** When a
   decision isn't clearly specified by the data or designs, check in before
   proceeding.

8. **Do not write application code until explicitly instructed.** Documentation and
   planning come first.
