# K-BIZ — Project Overview

## What This Is

K-BIZ is a Visual Communication graduation project: an interactive data-visualization
website that explores the development of K-pop through groups, generations,
historical milestones, and structured data.

The project is editorial in nature — it should feel like a digital exhibition or
interactive magazine, not a conventional dashboard or database.

## Central Screen: The Timeline

The main screen is a visual timeline containing approximately 150–200 K-pop groups.
Each group is represented by a pre-designed **charm asset** (SVG or image file).
These charms already exist and are the source of truth for how each group is
visually represented.

## Exploration Modes

The main screen offers three planned exploration modes:

### 1. Generations Mode (primary mode)
All groups are arranged by K-pop generation:
- 1st Generation
- 2nd Generation
- 3rd Generation
- 4th Generation
- 5th Generation

### 2. Top 10 Mode
A reduced, more approachable view presenting ten selected major groups from each
generation.

### 3. Discovery Mode
A more playful, curated or semi-random exploration mode that highlights a smaller
selection of groups and encourages free discovery. This mode should use
**controlled variation, not unrestricted randomness**.

## Filters

The main screen includes filters for:
- Generation
- Number of members
- Nationality composition
- Group type
- Formation method
- Main singing language
- Activity status
- Company size

Selecting a filter reorganizes or highlights the relevant charms while preserving
the overall visual language of the timeline.

## Group Detail View

Clicking a charm opens a detailed group view in the right-hand editorial panel.
This panel includes visual storytelling, images, factual information, and data
about the selected group.

## Design Character

The interface is intentionally editorial, dense, colorful, and unconventional.
It should feel like a digital exhibition or interactive magazine — not a
conventional dashboard or database.
